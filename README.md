# Transactions Dispute Portal

## Tech Stack
- Java (Spring Boot)
- React
- MySQL
- Docker

## Features
- User registration & login
- View transactions
- Dispute transactions
- Filter disputed/non-disputed
- Transaction history

## Run with Docker
docker-compose up --build

## API Endpoints
GET /api/transactions
PUT /api/transactions/{id}/dispute

## Testing
- Postman collection included
